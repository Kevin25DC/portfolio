        01
        
Sobre mí

        
Lo que hago y cómo lo hago.

      

      

        

          

            Soy ingeniero desarrollador Full Stack y construyo software para distintos
            dominios: ERPs y sistemas financieros, plataformas SaaS multi-tenant,
            puntos de venta, integraciones con APIs de terceros y
            productos con IA. Me especializo en sistemas de misión crítica, donde la
            exactitud del dato y la confiabilidad no son negociables.
          

          

            Me muevo cómodo en todas las capas: base de datos Oracle y PL/SQL a nivel
            de motor de liquidación, backends en Java EE y Python/FastAPI con
            arquitectura hexagonal, frontends en Next.js/React, e
            integraciones vía API REST y webhooks. Todo con pipelines de
            CI/CD y despliegues en contenedores.
          

          

            Hoy mi diferencial es la ingeniería con agentes de IA: diseño harnesses,
            skills, hooks y servidores MCP que convierten a modelos como Claude, GPT, Gemini o
            DeepSeek en un equipo de especialistas que trabaja con las reglas del negocio.
          

          
    
            
  • Causa raíz, no parches. Diagnóstico con datos reales antes de tocar código.
    • 
            
  • Blast radius mínimo. Cambios aislados, backups y rollback siempre listos.
    • 
            
  • Nada hardcodeado. Configuración parametrizable y trazable.
    • 
            
  • Código que se lee. SOLID, Clean Architecture, DDD táctico.

Harness Engineering

            
Diseño de harnesses para Claude Code y OpenCode: 22 agentes especialistas por módulo de negocio, pipelines de Product Owner y Desarrollo (radicar → analizar → construir → probar → revisar → documentar), hooks de validación y configuración multi-cliente.

          

          

            
RAG

            
Asistentes con Retrieval-Augmented Generation: embeddings, búsqueda vectorial en Pinecone, generación con Gemini, detrás de puertos/adaptadores para cambiar de modelo o de vector store sin tocar el dominio.

          

          

            
MCP & Tools

            
Servidores MCP propios (p. ej. acceso Oracle multi-cliente en solo lectura con bloqueo duro y auditoría de intentos de escritura), knowledge graph del código y automatización git para agentes.

          

          

            
AI-DLC · Spec-driven

            
Desarrollo guiado por especificación: PRDs, reglas y extensiones que el agente carga como restricciones duras; guardrails de seguridad (bloqueo de hosts de producción) y humano en el bucle para lo crítico.

          

          

            
Automatización

            
Flujos con n8n, bots de WhatsApp (Baileys), generación automática de reportes de gerencia y dashboards de pipeline a partir de issues de GitHub.

KARINA — Monitor de consumo de IA

          
App de escritorio local-first y multiplataforma (Windows / Linux / macOS) que monitorea en tiempo casi real el consumo de tokens, rate limits y saldo de Claude, OpenAI, Gemini y DeepSeek. Arquitectura de adaptadores por proveedor, polling con backoff exponencial, historial local con gráficos, alertas por umbral, exportación CSV/PDF y API keys guardadas en el almacén seguro del sistema operativo. Regla de oro: solo datos reales, nada inventado.
